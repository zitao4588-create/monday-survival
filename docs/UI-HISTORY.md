## 当前真实状态

- 当前游戏运行入口：`src/main.tsx` → `src/MondaySurvivalGame.tsx` → `src/components/` 响应式组件。
- 普通 H5 产物：`pnpm build` → `dist/`，包含备案页脚和分享能力。
- 小红书产物：`pnpm xhs:check` → `dist-xhs/`，然后将 `dist-xhs` 的内容打包，使 `index.html` 位于 ZIP 根目录。
- 自动验证覆盖本地构建与浏览器流程；小红书真实容器、真机、上传、审核和发布仍需在平台侧验证。
